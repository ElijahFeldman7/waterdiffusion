We introduce the first pairwise watermark for diffusion language models (DLMs), a class of large language models that generate tokens in a non-autoregressive, arbitrary order. DLMs offer advantages over traditional autoregressive language models (ARLMs) in agentic tasks by correcting errors during iterative noise refinement. Existing watermarking methods for ARLMs rely on access to previously generated tokens, which does not always hold for DLMs. Furthermore, DLMs operate through unmasking confidence scores, which provide less deterministic token biasing than logit-based methods. Our watermark defines a set of relative index rules that softly bias the unmasking process toward rule-consistent tokens. Experiments show that our proposed watermark achieves over 99% true positive rate at 1% false positive rate with minimal impact on generation quality.
